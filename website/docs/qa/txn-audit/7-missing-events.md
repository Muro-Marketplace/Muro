# Transaction audit 7: missing events

Adversarial completeness pass over reports 1 to 6, run 2026-08-28. Method: walk every journey from first principles as a person (buyer from browse to a year later, artist from application to leaving, venue from registration to a sale off their wall, admin week to week, and the platform's own legal and Stripe-account obligations), then keep only the moments that (a) no report lists and (b) the codebase demonstrably does not handle. Every row below was checked against the code and against all six reports before being recorded. No source code was modified.

Population note: two prompt-suggested areas were checked and found moot rather than missing. Artist applications carry no fee (no Stripe call anywhere in `src/app/api/apply/route.ts`), so "refund the application fee on deletion" cannot arise. And a price change between add-to-cart and checkout is re-priced server-side from the DB at session mint, with the final total shown on Stripe's hosted page before payment, so the buyer never pays an unseen price.
